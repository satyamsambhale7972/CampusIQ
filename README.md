# CampusIQ — Smart Campus Intelligence Platform

A premium, responsive front-end prototype with a midnight navy, electric indigo, violet and mint color palette.

## Included files
- `index.html` — website structure and content
- `style.css` — complete design system and responsive styles
- `script.js` — mobile navigation and smooth scrolling
- `campusiq-logo.jpg` — supplied CampusIQ logo image
- `README.md` — setup and deployment notes

## Run locally
Open `index.html` in a modern browser. Google Fonts requires an internet connection; the site remains usable if the external font cannot load.

## GitHub Pages deployment
1. Extract this ZIP.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and `campusiq-logo.jpg` to the root of your existing public repository.
3. If prompted, confirm replacing the existing website files.
4. Go to **Settings → Pages**.
5. Set source to **Deploy from a branch**, branch `main`, folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to finish publishing.

## Important
This is a front-end concept using illustrative sample data. It has no live backend, database, authentication, campus integration, or connected AI/ML model. All displayed metrics and recommendations are demonstration examples.
