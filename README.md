# CampusIQ — Smart Campus Intelligence Platform

A responsive front-end prototype demonstrating a connected campus experience for students, faculty, and administrators.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — simple navigation interactions

## Run locally
Open `index.html` in a modern browser.

## Deploy with GitHub Pages
1. Upload all four files to the root of your public GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then click **Save**.
5. Wait for GitHub Pages to publish the site.

## Important prototype note
This is a front-end demonstration using sample data. It does not include a backend, database, real authentication, or a connected AI/ML engine. Dashboard values and recommendations are illustrative only.
